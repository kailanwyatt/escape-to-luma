# Approved appearance references

These files are production references only. Runtime code must never import from
`assets/reference/`.

- `spark-profile-approved.png` — copied from the supplied Spark character/profile board; approved for Spark silhouette, energy layering and palette direction.
- `world-strip-approved.png` — copied from the supplied worlds board; approved for world palette and atmosphere direction.
- `obstacle-guide-approved.png` — copied from the supplied obstacle board; approved for obstacle silhouette and material direction only.
- `world1-opening-board-approved.png` — copied from the supplied World 1 opening board; approved for opening composition and Containment mood.
- `world1-level-board-approved.png` — copied from the supplied World 1 gameplay board; approved for environment dressing and readability.
- `campaign-concept-approved.png` — copied from the supplied campaign overview; approved as a high-level appearance reference.

Approval means “use as visual direction,” not “load this image at runtime.”
Gameplay dimensions, pivots, openings, movement and collision always come from
code/config. Generated text, layouts and obstacle geometry in the boards are
not authoritative.
