# Opening rebuild preview

`OpeningSceneV2` is a dev-only, live Three.js treatment for the existing campaign opening. It shares the production opening's beat clock, HUD, Level 1 handoff, and reduced-motion preference while keeping its own render-only meshes.

It adds layered star depth, a brighter capture pass, animated signal rings, containment-field lighting, fracture debris, and a camera path that finishes at the playable launch angle. It does not replace `OpeningScene` in ordinary gameplay.

In development, open **Settings → Preview new opening**.
