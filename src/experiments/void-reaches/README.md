# Void Reaches preview

`VoidReachesDemo` is a development-only visual study for the Null's replacement
tendrils. It is deliberately separate from `NullTendrilArt` and
`NullLashArt`: it owns no collision model and cannot change a campaign level.

In development, open **Settings → Preview Void Reaches**. The study loops
through a clear corridor, an amber surge warning, the narrow strike window,
and a cyan recovery. Two reaches define the active gate while a third stays
behind the action as decorative scale. Approving it is the prerequisite for
adapting this visual language to the playable Null encounters.
